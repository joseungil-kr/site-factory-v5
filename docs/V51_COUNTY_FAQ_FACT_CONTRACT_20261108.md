# V5.1 군 시험: FAQ 질문-답변 및 근거 소유권 게이트 (2026-11-08 후속7)

## 독립 실패 및 우선순위
계실장 독립 점수: 거창 /75 86점. '리본에는 어떤 이름을 적나요?' 질문에 옵션 0개로 답하는 문제, 옵션 정보 반복, 주문섹션과 리본 안내 중복이 발생했다. 청도/59와 완도/28의 90점 회복 및 과거 표본의 상품·주소·배송 근거를 보존한다. 단일 문구 치환만으로 통과 처리하지 않는다.

## 풀 항목 계약(18개 일반 구매목적+특수 구매목적 모두)
각 FAQ에 customer_question(구매 과업), answer_topic(답변 주제), answer_fact_ids(근거 원장 ID의 비어 있지 않은 목록) 또는 answer_kind=buyer_guidance(사실 외 일반 안내)와 action(고객의 다음 구체적 행동)을 명시한다. 확인된 실사실을 다루면서 비사실 안내로 위장해서는 안 된다. 선택옵션 수, 금액, 반입 조건, 배송료는 반드시 원장 근거를 연결한다. 답변 주제가 질문과 다르거나 앞 섹션의 같은 사실/행동을 반복하면 FAQ를 생략한다. 고객에게 필요한 한 문장의 다른 역할 요약은 허용하되 담당 슬롯을 기록한다.

실제 fact_id는 별도 고정 JSON 원장으로부터 로드해 검증 상태, 지역/시설 범위, 대상 SKU, 허용 출력 슬롯을 확인한다. 하드코딩 fact_id만 달아 원장 조회를 회피하거나 빈 배열을 비사실 안내의 표시로 사용하는 것을 허용하지 않는다. 출처 확인 시각을 기록하지 않았다면 unrecorded로 남기며 지어내지 않는다. 반입 공지는 notice, 가격은 카드, 주문 정보는 order, FAQ는 새로운 질문에만 배정한다. 사용자에게 보이는 총 상품명/가격의 필요 요약과 의미 없는 중복을 구분한다.

조립된 95 HTML을 대상으로 각 목적의 FAQ 질문-답변 대응(topic 일치), faq 사실의 원장 존재/확인 여부/제품/지역 범위/슬롯, 앞 섹션 중복을 검사한다. 리본 이름 질문에 '선택옵션0개·추가옵션0개'만 답하는 반례는 필수 FAIL fixture. 18개 일반 유형과 오브제3·쌀·쌀/바구니·영정바구니 및 허브를 검사한다. 규칙기반 감지는 전면적 의미 이해가 아니므로 95개 전수기계검사 외에 이전 FAIL을 포함한 최소 1% 이상 실제 HTML·390/1440 화면을 사람이 읽고 독립 판정을 받는다.
