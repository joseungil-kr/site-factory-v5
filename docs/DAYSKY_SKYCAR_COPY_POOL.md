기존의 화분용 `v5/neutral_copy.py`를 다른 업종에 재활용하지 않고,
스카이차 현장의 작업 조건과 전화 상담을 설명하는 POOL을 새로 작성했습니다.

  외벽 점검·보수, 간판 설치·교체, 유리·창호 지원, 외벽 도장, 시설물 유지관리,
  통신·조명설비, 외부 배관·공조설비, 현수막·옥외 광고물 등 **8개 작업 유형**.
  각 유형마다 도입·작업 상황·접근 조건·공정·상담 정보를 분리합니다.
- [공통 현장 POOL](../data/pools/daysky_shared_pool.json): **140개** 문장.
  지역 맥락·진입로·지반·장비 선택·작업 시간·비용·안전·현장 사진·작업팀 협의·전화 상담의 **10개 그룹**.
- 합계 **524개 완전히 서로 다른 문장**. 내용은 독립적으로 작성했으며 실제 시공 실적, 지역별 지형, 사고 이력, 확정 출동 가능 시각을 창작하지 않습니다.
- 금액은 기존 `sites/daysky/rates.json`에서 관리하므로 POOL에 금액을 하드코딩하지 않습니다.

## 3. 1% 무작위 전수 대조 방식

- 난수: Python `random.Random(seed)` 사용. 시드는 기록하며 재현 가능합니다.
- 서울 807개에서 **9개**, 경기 900개에서 **9개**를 무작위 추출합니다.
- 각 18개 샘플을 **전체 1,736개 후보·기존 문서 전부**와 비교합니다(자기 자신 제외).
- 각 시드마다 18 × 1,735 = **31,230쌍**을 검사하며 3개 시드 합계 **93,690회 비교**합니다.
- 유사도는 V5 기존 감사 코드와 같은 **공백 제거 문자 5-그램 Jaccard**입니다.
- 샘플별 *가장 높은 유사도*가 **0.49 미만**이어야 통과합니다.
- 별도로, 1,736개 전체에서 본문 SHA256의 **완전 동일 중복을 전수 검사**합니다.

## 5. 향후 확장 전 확인할 사항

1. 다지역 생성기는 기존 `sites/daysky/pages.json`을 덮어쓰지 말고 새 문서를 누적·검수해야 합니다.
2. 새로운 URL의 제목, 설명(meta description), FAQ, 장비·요금표, 실제 작업 사진을 검수해야 합니다.
3. 법정동·읍·면을 포함하려면 별도의 지역 원장을 확보해야 합니다.
4. 전체 공개 전에 1% 표본 외에 **지역·작업 유형별 고유성 및 검색 의도**, 유사도가 높은 상위 문서 쌍을 추가 점검해야 합니다.
5. 현재 생성기는 **시뮬레이션 전용**입니다. 이 POOL 반영만으로 공개 웹사이트에 새 URL이 생기거나 SEO 설정이 바뀌지 않습니다.
