## 새 사용자 지시에서 확인했으나 조건 정의가 필요한 주장

1. **마진율 60~70%**: 재료비 차감 매출총이익률인지, 카드/포장/연료/폐기 포함 공헌이익인지, 인건비·임차료 포함 순이익률인지 불분명. 실제 원가표와 판매가가 필요함. 원고/배너에 확정 성과·보장 수익으로 사용 금지.
2. **초도비용 0~100만원**: 초기 계약부담금/장비비/첫 재료 매입금/장소/시설/보증금 중 어느 범위인지 불분명. 기존 사이트의 월 최소 식자재 100만원과 관계 확인 필요.
3. **1주일이면 운영 시작**: 허가·장소·전기/환기·교육·발주 준비가 완료된 뒤 장비 설치를 기준으로 한 일정인지 확인 필요. 모든 창업형태에 적용되는 보장 문구 금지.
4. **1평 샵인샵**: 실제 기계 크기·작업·소독·환기/전기·안전 동선·영업신고 요건에 따라 실현 가능 여부 달라짐. 모든 매장에 1평 가능 단정 금지.
5. **잉어빵·계란빵·십원빵**: 사용자 지정 창업 상담 품목. 참조 백세 분식의 확인된 식자재는 붕어빵 반죽·팥소·슈크림이며, 나머지 3종의 실제 기계·반죽/속재료 조달·교육 지원 범위는 확인 전.
6. **대리점 모집**: 본사의 공급계약형 판매점인지 브랜드·상표·운영관리 조건이 있는 가맹사업인지 구분 필요. 정보공개/가맹 관련 법적 판단은 계약 내용 확인 후 진행.
