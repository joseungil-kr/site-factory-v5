# flower.nalmada.net — 실제 콘텐츠 우선 디자인 검수 기록

상태: **디자인 방향 선택, 최종 승인 전**. 공개 배포·DNS·색인 제출 금지.

## 사용자 결정
- 메인 히어로: **B안(그린 프리미엄)**. 브랜드의 핑크/그린 색상은 유지
- 전국 서브페이지: **C안(지역+상품형), D안(시설형) 병행**
- 2×2 이미지 시안은 컨셉 보드일 뿐 최종 HTML 구현의 증거가 아니다.
- 모든 레이아웃은 실제 생성된 조합 텍스트와 실제로 확보 가능한 사진·상품·시설 데이터 기준으로 작성한다.
- 최종 디자인 승인 전 배포하지 않는다.

## 컨텐츠 기반 설계 요구사항
**C안 / 지역+상품형**:
1. 제목·지역·핵심상품별 도입문 + 사용 가능한 공통 히어로 이미지, 전화 CTA
2. 조합된 본문 4~6개 섹션을 가독성 중심의 **문서형 세로 레이아웃**으로 렌더링(각 H2, 문단, FAQ).
3. 가격·상품 카드: 확인된 제품 ID, 이미지 URL, 현재 판매 가격, 실제 주문 URL이 존재하는 경우에만 표시. 미확인 값은 가상 가격으로 채우지 않는다.
4. 지역 링크/페이지네이션/하단 상담 CTA. 지역명만 바뀌는 과장 현장 이야기를 생성하지 않는다.

**D안 / 시설형**:
1. 장례식장 등의 **실재·주소·시설 정보 확인**된 시설에만 시설형 레이아웃을 제공.
2. 시설 이미지·지도·주차·운영시간 등은 각 데이터가 검증된 때만 노출. 미확인 경우 관련 UI를 제거하고 문서형 안내 본문으로 대체.
3. 시설별 문구를 근거 없이 복제하지 않으며 배송 가능·가격·시간은 확인된 값만 표시.
4. 시설 정보보다 본문이 길더라도 내용과 CTA가 안정적으로 배치되게 반응형 템플릿 제공.

## 시안 검수 게이트
- 샘플: 메인 1, C안 지역 2, D안 실제 확인 시설 2, **정보가 비어 있는 시설 1**.
- 콘텐츠 데이터로 렌더링된 실제 HTML/CSS, PC(1440px)와 모바일(390px) 스크린샷 제공.
- 텍스트 2,500~3,000자(해당 유형의 목표 분량 확정 후), 길고 짧은 제목, 4~6 섹션, FAQ 및 CTA를 실제 배치해 확인.
- 이미지가 0/1/여러 개인 경우, 상품 0/4개인 경우, 시설 메타 0/일부/전체인 경우의 결손값 테스트.
- 깨진 링크·수평 넘침·모바일 표·중복 CTA·빈 칸·이미지 저작권/실제성 점검.
- 사용자 검수 후 최종 승인 버전과 시안 식별자를 site-spec.json의 designReview에 기록.
- 승인 전에는 운영 페이지 생성 및 배포 불가. 여기서 말하는 시안 구현은 **검수 전용**이다.

## 유의
이 문서 자체는 디자인 승인도 실제 구현도 아니다. 2×2 그림 속 허구의 59,000원, 임의 시설 전경/지도는 실제 데이터로 간주할 수 없다.
