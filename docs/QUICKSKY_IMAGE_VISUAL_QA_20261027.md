## 승인과 제한
- 직접 사용자 진술과 원본/파생물 SHA, 실제 시각 내용, 오인 방지를 위한 UI 수정은 **지목된 두 사진의 빠른스카이 홍보용 재사용**에 대한 실무 근거이다.
- 이미지 QA 판정: `imageAssetsApproved=true`로 허용 가능 (정확히 이 이미지 셋·중립적 설명 조건에 한정); 무관한 신규 이미지는 재검수.
- 이는 도메인/콘텐츠 품질/실제 차량 보유/촬영자 신원/모델 톤수의 인증이 아니며, **`contentQualityApproved`와 `publicIndexingApproved`는 별도**이다.
- 진단 시점의 라이브 noindex Worker는 이전 배포 SHA이므로 UI 수정 사항이 즉시 적용됐다고 보고하지 않는다.
