# 사이트팩토리 V4·V5 이미지 출처·생성·사용 승인 규칙

**시행 기준:** 사용자의 2026-10-30 직접 지시.  
**기본값:** 사진/삽화는 **실제로 이미지 생성 도구가 만든 원본**을 사용한다. 실물 사진이 필요하다는 이유만으로 인터넷 사진을 수집하거나 생성 이미지에 '실제'라고 표시하지 않는다.

## 1. 사용 가능한 출처 분류

| 코드 | 사용 조건 | 공개 검수 |
| --- | --- | --- |
| `GENERATED_VERIFIED` | 이미지 생성 도구 실행 원본, **실제 요청문**, 생성 시각, 도구 응답 참조, 최종 편집 파일과 SHA256까지 서로 연결됨 | 통과 후보 |
| `USER_APPROVED_EXTERNAL` | 원본 URL/이미지, 사용자의 **명시적 허가** 증빙(정확한 대상·범위), 원본/파생 파일 SHA256 있음 | 그 정확한 범위에 한해 통과 후보 |
| `USER_SUPPLIED_ORIGINAL` | 사용자가 원본 파일과 사용 권한을 직접 제공한 사진, 그 범위 기록 | 해당 범위 통과 후보 |
| `GENERATION_EVIDENCE_PARTIAL` | 생성 도구 결과 ID는 확인되지만 정확한 요청문·시각 또는 원본→최종 매핑이 빠짐 | **새 공개·교체·확장 시 검수 보류**; 기존 운영 파일은 보존 |
| `SOURCE_UNVERIFIED` | 출처/실제 생성 도구 결과를 확인 못 함 | **새 공개 검수 보류**. 자료 확보 또는 새 생성본으로 교체 |
| `RESEARCH_ONLY` | 경쟁사 조사·UI 레퍼런스·검색 캡처 | 자료 조사에만 보존; 제품/배너/본문 제작 이미지로 사용 금지 |

**금지:** 검색·SNS·경쟁사·블로그·지도에서 무허가 다운로드/핫링크/복사/크롭/리터칭/스타일변환; 유명 브랜드·사이트의 소유를 유추해서 권한 확대; 출처 불명에 AI생성 라벨만 붙여 재분류; 상품/공급/배송/시공·실매장 성과를 묘사한 AI 연출을 실제 수행 증거로 표시.

## 2. 예외: skycar1day.com 정확한 사용자 허가

사용자는 2026-10-30 **`skycar1day.com 사진은 사용해도 좋음`**이라고 다시 명시했다. 이는 해당 사이트 사진의 사용 허가로 기록하고, 다른 스카이차 업체·관련 도메인·검색 결과로 확대하지 않는다.

기존 V5 승인 사진 3개는 아래 명시 원본에서 전환된 것이 `docs/DAYSKY_PHOTO_PROVENANCE.json`에 해시와 함께 기록돼 있으므로 **재생성하거나 교체할 필요가 없다**.

- `assets/library/daysky/skycar-hero.webp` ← `https://skycar1day.com/images/yjsky_02.jpg`
- `assets/library/daysky/skycar-facade.webp` ← `https://skycar1day.com/images/yjsky_01.jpg`
- `assets/library/daysky/skycar-truck.webp` ← `https://skycar1day.com/images/yjsky_02.jpg`

그 외 도메인의 이미지들은 '본인 사업', '같은 대표', '공개 웹페이지' 등의 추정만으로 허가하지 않는다.

## 3. 생성형 이미지의 필수 증빙 (신규 제작)

파일 하나마다 기계 판독 가능한 JSON에서 다음 정보를 **정확히** 보존한다.

1. `assetPath`, 사용 사이트와 용도(`hero`, `menu_illustration`, `background` 등).
2. `sourceType=GENERATED_VERIFIED`, 사용된 생성 도구의 정확한 식별자.
3. **실제 실행한 전체 요청문** `toolPromptVerbatim` (한글/영문 원문, 재구성 금지), 사용자 크리에이티브 요청문 `userRequestText`.
4. **생성 시각** `generatedAt` — 도구/시스템이 남긴 UTC ISO-8601 원자료. 알 수 없다면 null; 파일 업로드 시각이나 검수 시각을 생성 시각이라고 쓰지 않는다.
5. `toolResultRef`, 가능하면 `generationId` — 실제 응답에서 받은 원본 참조.
6. `originalFilename`, `originalSha256`, `originalArchiveLocation` — 도구 결과 원본을 장기 보존할 수 있는 위치.
7. `transformations` — resize/crop/format/webp quality/편집 도구, 입력·출력 관계(다른 이미지 섞기 포함).
8. `finalSha256`, `finalBytes`, `assetPath`가 실제 Git 저장 바이트와 일치.
9. `depictedFactRole=illustration` 또는 `actual_verified_photo`를 별도로 기록. AI 생성은 실제 수료생·시공·상품 납품 실적의 증거가 될 수 없다.
10. 사용자 승인 범위 및 실제 공개에 사용한 페이지/빌드 SHA.

프롬프트가 도구 결과 메타데이터에 비어 있다면 빈 문자열을 만들어 채우지 않는다. 사용자 피드백 문장은 **userRequestText**로 보존할 수 있지만 실행 프롬프트와 동일하다고 단정하지 않는다. 출처 미확인은 파일명/라벨/해시만으로 해결되지 않는다.

## 4. 사용 승인 사진·실제 상품 사진 구별

- 제품 식별을 요구하는 상품 사진은 실제 제품의 허용된 이미지가 확인되어야 한다. 일반적인 AI 연출 사진을 특정 실재 상품·납품 사례로 치환하지 않는다.
- 온라인의 상품 원본 출처가 기록돼도 사용자 허가·구체 상품 사용 범위까지 검증되기 전에는 **다른 사이트로 재사용하지 않는다**.
- AI 사진은 소개 이미지/상차림 연출/컨셉에 사용하며, 조리 실습·매장·화환 배송/설치·시공 사례를 실제 기록이라고 표시하지 않는다.
- 파일이 GitHub에 이미 커밋돼 있거나 HTTP 200으로 공개돼 있다는 사실은 생성·저작권·실적 증명이 아니다.

## 5. 발행/유지관리 안전 게이트

1. 새 사이트/새 이미지 사용 전에 **경로와 asset role**을 확인한다.
2. 해당 이미지의 정확한 원본·권리·생성 기록을 검증하고 해시·도구 참조를 readback한다.
3. 출처 미확인/권한 미확인은 해당 신규 이미지와 관련된 **공개 검수만 HOLD**. 이미 승인된 다른 페이지, 실물 상품, IndexNow, 운영 Worker를 일괄 중단하지 않는다.
4. 대체가 필요하면 **새 이미지 생성 → provenance 기록 → 기존 파일 대비 페이지별 변경 검토 → 브라우저 QA → 별도 PR → 승인된 배포** 순서로 진행한다. 무단 일괄 삭제나 무검증 이미지 교체 금지.
5. 이미지 품질: 최소 모바일 390px / PC 1440px, crop·본문 가시성·실물 오인 방지·대체텍스트·이미지 200/정확 해시 확인.
6. 백세푸드·겨울붕어빵의 **기존 생성 원본 자료**는 사용자 Library의 `/SiteFactory/image-origin/2026-10/`에 보존하고 파일명/해시/도구 gen ID를 site별 manifest에 연결한다. 누락된 정확 실행 프롬프트 및 생성 시각은 검증 전 **미확보** 상태로 둔다.

## 6. 확인된 현행 상태 / 범위

- V5 `daysky` 실사 WebP 3개: **정확한 skycar1day.com 원본 URL 및 사용자 허가**에 한해 유지.
- V5 `promotion-plant` WebP 5개·SVG 3개: 생성기 gen ID/권리 증빙 없음 → **다음 공개·다른 사이트 재사용 HOLD**.
- V5 `daysky` SVG 3개: 코드/이미지 생성 원본 도구 이력 불명 → 신규 공개 시 확인 필요. 승인된 skycar 사진 3개의 사용 권한까지 뒤집지 않는다.
- 기존 V4 상품사진: `fwith.co.kr` 등 상품 식별 목적의 원본 URL/해시는 일부 있음. **상품 사진은 생성 연출과 구분하여 개별 범위 확인**. 기존 운영 및 상품 목록은 변경하지 않는다.
- V4 전국 꽃/근조 배너 4개: 생성 결과/권한/원본 세부 증빙이 없어 **추가 사용 및 재발행 HOLD**.
- V4 경쟁사 이미지 조사 증거: `docs/research/IMAGE_ROLE_REVIEW.md`에 조사용이며 제작 자산이 아니라고 기록됨. 경쟁사 이미지를 다운로드했다는 이유로 제작에 사용할 수 없다.
- `baekse` WebP 5개: 실제 이미지 생성 결과 gen ID와 생성 원본 PNG5개가 확인되고 원본→최종 픽셀 대응을 검증함. **정확한 도구 프롬프트·생성 시각 미확보**는 별도 기재. 이미 운영 중인 사이트와 상품은 보존.
- `winterbbang` WebP 5개: 원본 생성 콜라주5개·gen ID는 확인되나 **최종 각 크롭과 원본 콜라주 간 확정 대응 미완료**. 기존 운영을 일괄 삭제하지 않는다.

## 7. 스코프

본 규칙은 새 작업/새 공개에 적용한다. 기존 운영 버전 변경은 별도 변경대상 표·실제 경로/해시·원인/권리/품질 근거·롤백을 확인한 뒤 진행한다. 단순 문서/검수 PR이 배포 완료를 뜻하지 않는다.
