# 날마다꽃 전국 장례식장 확장 상태

- 목표: 전국 장례식장별 '{장례식장명} 근조화환 주문 가격안내' 페이지
- 실제 등록된 검증 원장: **1곳** (안산제일장례식장). 외부 확인 출처 및 검증일은 JSON에 기록.
- 전국 장례식장 원장은 아직 확보하지 못함. 지역 이름에서 가짜 시설명을 합성하지 않는다.
- 독립 근조화환 문구 POOL: 샘플 27문장 기반 48문장으로 확대. 전국 대량 공개 수준의 다양성·유사도 49% 검증 전.
- 출력: noindex 미리보기 HTML, 공통 근조화환 이미지 영역, 가격은 실제 판매정보 검증 전 공란 대신 상담 확인.
- 운영 배포: 디자인 최종 승인과 시설 데이터 및 상품 가격 검증 전 금지.
- 실행: `python scripts/build_flower_funeral_national.py`
- 이후: 검증된 시설 원장을 수집·증량 → 전용 문구 POOL 보강 → 1% 샘플 vs 전체 문서 유사도 검사 → 품질·이미지·가격·HTTP 검수 → 승인된 범위 단계적 공개.
