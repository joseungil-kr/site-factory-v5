# WreathPrice 고객 문구 제작 프롬프트 및 검수 규칙

## 적용 경로
고객용 HTML은 `build.py` → `expand_nationwide.py` → `expand_lower.py` → `customer_copy.apply_to_tree` 순서로 생성한다. 고객 문구 풀은 `customer-copy-pool.json`. 수정을 개별 4,935개 HTML에 하지 않는다.

## 제작 요청서
당신은 실제 화환 상품을 비교하여 주문하려는 고객을 돕는 한국어 커머스 편집자입니다. 특정 지역 이름은 주소 검색·안내용 구분에만 사용합니다. 확인되지 않은 현지 제작처, 지역 지점, 반입 허가, 최저가·무료배송, 배송 시간이나 실제 납품 사실을 만들지 마세요.

고객의 의사결정 순서는 ① 용도(근조/축하) ② 상품 형태(3단/오브제) ③ 실제 판매 상품별 기준가 ④ 받는 시설과 주소 ⑤ 배송비·리본 문구·옵션 ⑥ 결제 직전 총액 확인입니다. 제목·단락·표·FAQ·이미지 캡션은 이 흐름에서 실제 행동을 돕는 문장으로 작성합니다.

검증된 가격은 B201 59,000원, B203 79,000원, B205 109,000원(2026-10-22 기존 판매처 원장), C205 149,000원, C030 200,000원(2026-10-30 확인 기록)입니다. 이는 최종 결제액이나 현재 재고의 보장이 아니므로 날짜를 붙여 표시합니다. 동일 용도 근조 3단끼리 가격을 비교하고 축하 3단·축하 오브제를 다른 형태의 상품으로 설명합니다. 가격 차이를 꽃 수·크기·품질 차이로 꾸며내지 않습니다.

지역별 배송비·리본 포함 여부가 미확인일 때는 "받는 시설명과 상세 주소를 알려주시면 주문 가능 여부와 추가 비용을 안내받을 수 있습니다"와 같이 간결하게 작성합니다. "증명되지 않았다", "보장하지 않는다", "사례 0건", "AI가 만들었다", "시안", "먼저 확인하세요"를 불필요하게 반복하지 않습니다. 필요한 제품 시각자료는 "상품 형태 참고 이미지 · 실제 판매 상품과 다를 수 있습니다"라고 안내하며 배송 현장이나 실물 사진인 것처럼 말하지 않습니다.

## 코드·검증 통합
- 정확한 SKU와 `https://fwith.co.kr/shop/item.php?it_id=...` 상품 링크 5개를 유지한다.
- 실제 WebP 다섯 장의 바이트와 주소, HTML 페이지 4,935개 및 공식 법정동 원장 고정 SHA를 변경하지 않는다.
- 이미지 ALT·캡션, 표 가격, FAQ, 푸터, 허브 내비게이션, 제목·메타 설명까지 검토한다.
- 고아페이지 0, 내부 404 0, noindex 누락 0, canonical/sitemap/RSS 현행 정책 보존.
- 최종 HTML에서 불필요한 내부 제작 언어와 가르치는 문장을 검수하고 `test_customer_copy_quality.py`로 16개 광역권·3가지 페이지 유형을 포함하는 최소 50개를 평가한다.
- 자연스러움25/근거30/구매도움30/반복15점으로 항목별 기록한다. 90 미만 한 개라도 발견되면 배포 실패, 문구 풀·생성기 수정 후 **새 표본을 포함**해 재검수한다.
- 자동 검수 점수는 검색엔진의 고유 콘텐츠 평가나 실제 지역 배송 가용성의 검증을 뜻하지 않는다. 배송 근거가 없으면 인덱스 전환 없이 noindex 유지한다.
