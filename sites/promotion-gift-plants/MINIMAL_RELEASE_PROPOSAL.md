# 작업자6: 품질 우선 최소 공개 대안 (미승인)

## 결정 대상
기존 5,302개 전국 지역 후보는 조사 원장으로 보존한다. 지역명만 다른 페이지의 일괄 공개는 금지한다. 이번 제안은 **최종 공개 범위 승인 요청안**이지 승인된 변경이 아니다.

## 1차 공개 후보: 5개 핵심 페이지
| 번호 | URL 초안 | 내용 | 필수 조건 |
|---|---|---|---|
| 1 | `/` | 목적별 상품 탐색, 연락·주문 흐름, 검증된 상품만 표시 | 실제 이미지 연결·가격·주문 검증·도메인 확인 |
| 2 | `/promotion.html` | 승진 선물: 책상용·소형 비교, 직함/리본 입력, 수령 부서 확인 | 상품 구성/옵션/리본 사실 검증 |
| 3 | `/transfer.html` | 영전·전보: 발령일·새 근무지·대리수령, 상품 선택 | 배송 조건과 상담 흐름 검증 |
| 4 | `/congratulations.html` | 일반 축하: 공간·메시지·받는 사람에 맞는 선택 | 상품 선택 근거 및 실제 구성 |
| 5 | `/same-day-inquiry.html` | 당일 문의: 지역·시간·SKU·담당자 순서, 보장 표현 배제 | 실제 상담 가능 채널·운영시간 검증 |

모든 URL은 제안이며 현재 V5 번호 기반 렌더러의 실제 URL 계약과 다르다. 별도 라우팅 또는 정적 alias가 필요한지 기존 코드로 확인해야 하며, 허위로 이미 존재한다고 표시하지 않는다.

## 지역 페이지: 조건부 추가
- 최초 강진군 대구면·성전면은 **공개 후보에 넣지 않는다**. 면사무소 주소와 진로체험시설 목록은 실제 화분 주문의 수령 가능성·배송 범위를 뒷받침하지 않는다.
- 실질적인 배송지역·추가요금·마감·수령 절차 또는 거래/행사장의 실제 검증 정보가 있는 지역만 추가한다.
- 지역 페이지당 출처, 확인일, 상품과 수령 시나리오, 실제 주문자에게 유용한 차이, 기존 문서 대비 의미적 독립성, 이미지/권리 상태를 검수한다.
- 지역 근거가 없는 경우 5개 목적 페이지에서 주소별 상담을 받도록 하고 별도 지역 문서는 만들지 않는다.

## 공개 게이트
1. 이미지 WebP 원격 등록과 안내 문구, 실제 390/1440 스크린샷.
2. 상품 상세/가격/옵션/배송 가능성의 확인 가능한 최신 원문.
3. V5.1 plan-check, audit, 목적별 독립 편집 검수(85점 기준), 상품 링크/모바일/PC 검수.
4. DNS/Worker 상태에 따른 정확한 변경 승인. 공개 승인 전 검색 등록·IndexNow 금지.
5. 전국 5,302개 공개는 별도 사업·SEO 품질 검토 후 재결정.

## 실패쌍 실험 해석
같은 목적/상품의 증거 전후 유사도 비교는 문장 추가의 영향만 보여준다. 주소·시설 나열로 점수를 맞추는 것은 상업적 유용성이나 지역 페이지 공개 근거로 인정하지 않는다.
