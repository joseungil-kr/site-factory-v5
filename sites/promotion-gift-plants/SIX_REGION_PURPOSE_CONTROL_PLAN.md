# 전국 독립문서: 공통 운영정책 및 구매흐름 6지역 통제검증 계획
작성일 2026-11-09. 현재 대표 5페이지 수정은 **목적별 공통정책 정합성**만 개선한다. 전국 5,302개 독립문서 품질 합격이 아니다.

## 실제 적용 규칙
1. 전국 공통 운영정책은 `operator-service-confirmation-20261109.json` 단일 원장에서 생성. 08:00~23:00 전화 주문과 지역 꽃집 운영시간에 따른 06:00~20:00 배송 가능 시간대, 지역별 지점 발송 및 전국 당일배송 서비스 가능, 개별 도착·마감·재고·추가요금 전화 확인을 구분한다. 문서 유사도 개선을 위해 정책을 변형하거나 일부 페이지에서 누락하지 않는다.
2. 상품·예산·난류 비교는 검증된 SKU 원장에서 생성. 승진은 새 직책/보내는 관계/문구→상품→수령 부서, 영전은 발령일/출근일/이전주소 오류→상품→새 근무지 수령의 실제 결정 순서를 따른다.
3. 회사·자택·행사장 수령은 **모든 지역에서 고객이 선택할 수 있는 경로**로 제공한다. 배송비 표 상태를 수령 유형과 결합하지 않는다.
4. 지역 고유 모듈은 판매처 배송비 원문과 실제 주문 주소 식별·수령에 도움 되는 확인된 지역 사실만 허용. 시설명 나열, 지역 배송실적·지점 주소·반입규칙 추정 금지. 확인일·출처·원문값은 내부 원장에 보존하고 고객에게는 필요한 질문·상담 행동으로 표현.
5. 같은 지역명을 바꾸거나 목적 모듈 순서·동의어만 바꿔 49% 기준을 맞추지 않는다.

## 동일 목적·동일 운영조건 통제 6지역
- 정확 읍면 배송비 표시: 파주시 적성면 / 양평군 단월면
- 시군구·읍면 중복 표시: 가평군 설악면 / 포천시 이동면
- 행정명 매칭 미확인: 강진군 대구면 / 영광군 법성면

각 지역 **승진 목적**으로 같은 6개 검증 상품, 동일 공통 운영정책, 동일 고객 수령 선택 경로를 사용한다. 배송비 원문에서 실제 관측되는 차이만 변경한다. 전체 HTML, 본문 원문, 15쌍 유사도, 상품카드/가격/링크, FAQ, 정책 출처, 모바일 390/PC 1440 화면을 수집한다. 같은 상태 쌍을 별도 표기해 지역명만 다른 반복을 우선 적발한다.

## 통과 조건과 후속
- 49% 기준은 기존대로 적용. 유사도 통과만으로 품질 85점 인정하지 않는다.
- 최소 1% 직접 읽기(5,302 기준 최소 54문서) 검수는 전국 확장 단계에 별도 수행한다.
- 실제 지역 고유 구매결정 근거가 부족하면 **불합격으로 기록**하고 임의 내용을 넣지 않는다.
- 공개·검색 등록·이미지·CF·기존 사이트 변경 금지. 운영자료 빈 인계양식은 유지.
