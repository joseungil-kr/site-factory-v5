## 권장 수정과 배포 게이트
1. **사진 본문 P0**: Clinicflower/Clinicopen의 이미 확보된 화분 AI WebP를 실질적으로 연관된 본문에 `<img src alt width height>`로 삽입. 첫 화면용 이미지 우선 로드, 나머지는 lazy-load, 레이아웃 이동 방지. 동일 이미지 15,906회 노출만으로 검색 대표 사진이 된다고 주장하지 않는다.
2. **Clinicpresent 전용 사진 P0**: 실제 꽃/화환을 묘사한 신규 생성 원본 또는 사용 범위가 검증된 축하화환 이미지가 필요. 기존 화분 이미지를 축하화환 실물로 가장하지 않음. 출처·프롬프트·도구 결과·생성 UTC·변환 SHA 등 V5 provenance 확인 후 공개.
3. **메타 태그 P0**: 고유 `og:type/title/description/url/image`과 적합한 `twitter:card/image` 추가. `og:image`는 호스트별 절대 HTTPS URL이며 실제 200·내용 관련성·이미지 규격 확인. 문서별 이미지 고유성이 부족하면 모든 지역에 허위 대표성을 주장하지 않음.
4. **구조화 데이터 P1**: `BreadcrumbList`(실제 방문자 표시/내부 URL과 일치)·`WebPage`·확인 가능한 `Organization` 정보만 JSON-LD로. 실제 주소 없는 지역별 LocalBusiness, Review/AggregateRating, 상품 가격, 보장 배송은 만들지 않음. FAQPage 리치 결과는 일반 상업 사이트에서 기대하지 않음.
5. **실제 품질 P0/P1**: 동일한 지역명 치환·절차문 반복을 넘어 각 호스트가 제공하는 개원화분/개원식/축하화환의 실질적 정보 가치와 주문 의도를 사람이 검토한다. 49% 문서 유사도만 검색 순위 보장은 아님.
6. **QA P0**: 전국 생성 HTML 전체에 `title/description/canonical/OG/index/1 H1/적합한 image alt` 검사와 대표 실제 브라우저 390/1440(자연너비·화질·전화 버튼·LCP/CLS)을 필수로 강제. 이미지가 없는 HTML이나 키워드/허위 내용으로 대체된 OG는 발행 차단.
7. **재배포/색인 P0**: 수정 빌드 SHA, 기존 Worker ID/도메인 바인딩/이전 버전 스냅샷 보존; URL별 HTML/이미지 HTTP200·canonical/OG readback 확인. 변경된 URL만 합법적으로 IndexNow 재알림하고 접수와 실제 색인은 분리. 재생성보다 현재 버전/이미지/QA가 우선.

## 범위
